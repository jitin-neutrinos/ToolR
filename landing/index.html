Plain English

What ToolR does for you

Think of it as a concierge standing between you and your AI assistant. You say what you want in your own words; the concierge quietly hands the assistant a note listing exactly which of its hundreds of tools fit this job — and stays quiet when nothing fits.

👁

It watches every prompt

Each message you type is read the moment it arrives — on your machine, in milliseconds. Nothing is sent anywhere; the whole brain is local.

🧭

It suggests the right tools

A ranked card rides along with your prompt: the skills to load, the MCPs to call, the agents to spawn — each with a score and the reason it matched.

📈

It learns what you use

When a suggestion is actually loaded, ToolR remembers. Over days its picks get sharper, its card depth adapts, and one trusted path gets shorter.

Under the hood

The full pipeline

Two independent retrieval lanes — lexical BM25 and local embedding vectors — see the same enriched corpus, are fused by a convex blend, then shaped by four cheap filters. Every stage fails open: if a lane dies, the previous stage's answer ships. Nothing on this path ever blocks your message.

Get started

Install in one line

The script finds your harnesses, shows you what it found, installs the router everywhere it fits, and leaves one launcher behind. No accounts, no API keys, no cloud.

# one line — detects harnesses, installs everywhere it fits
$ curl -fsSL https://toolr.jitinnair.com/install.sh | bash
# already cloned? keep it fresh instead:
$ git -C ~/toolr pull && python3 ~/toolr/install.py
# same installer — macOS uses the standard bash + git that ship with it
$ curl -fsSL https://toolr.jitinnair.com/install.sh | bash
# requirements: git + python3 (xcode-select --install covers git)
# PowerShell 5.1+ — no WSL needed
PS> irm https://toolr.jitinnair.com/install.ps1 | iex
# requirements: git + python (winget install Git.Git Python.Python.3.12)
# then route from any terminal:
PS> ~\.tool-router\route.cmd "your request here"
  1. Detect — the installer probes for every supported harness and shows you the found list before touching anything.
  2. Wire — skills are symlinked into each harness, the per-prompt interceptor is registered, and the routing mandate is written into the harness's rulebook as a marked, self-healing block.
  3. Index — every skill, MCP, agent and command on the machine is indexed (lexical + embedding vectors) in about a second.
  4. Verify — route a prompt and watch the card arrive with scores and match reasons.
