Installation

One line. Everywhere it fits.

The installer probes every supported harness on your machine, shows you what it found with a live TUI, wires each one with the right interceptor, and verifies with a real routing card. No accounts, no API keys, no cloud.

# one line — detects harnesses, installs everywhere it fits
$ curl -fsSL https://toutur.jitinnair.com/install.sh | bash
# already cloned? keep it fresh instead:
$ git -C ~/toutur pull && python3 ~/toutur/install.py
# macOS — same installer (needs git + python3)
$ curl -fsSL https://toutur.jitinnair.com/install.sh | bash
# git comes with the Command Line Tools:
$ xcode-select --install
# PowerShell 5.1+ — no WSL / Git Bash needed
PS> irm https://toutur.jitinnair.com/install.ps1 | iex
# prerequisites if missing:
PS> winget install --id Git.Git -e
PS> winget install --id Python.Python.3.12 -e
# then route from any terminal:
PS> ~\.tool-router\route.cmd "your request here"

What the installer does

  1. Detect — probes Claude Code, Codex, Gemini, Antigravity, Cursor, OpenCode, OpenClaw, Hermes and the shared ~/.agents location, and lists what it found before touching anything.
  2. Wire — symlinks the skill into each harness, registers the per-prompt interceptor where the harness supports one, and writes the routing mandate into its rulebook as a marked, self-healing block.
  3. Index — indexes every skill, MCP, agent and command on the machine (lexical + embedding vectors) in about a second.
  4. Verify — you route a prompt and watch the card arrive with scores and match reasons.

Verify your install

# should print a card with ranked picks and scores
$ ~/.tool-router/route "profile a slow python service"
# full self-check (44 checks)
$ python3 ~/toutur/scripts/selftest.py
Local model (optional): the semantic lane uses Ollama with nomic-embed-text when present, and the router stays BM25-only without it — everything degrades gracefully. ollama pull nomic-embed-text is the one optional step.

Uninstall / update

# update = pull + re-run the installer (idempotent)
$ git -C ~/toutur pull && python3 ~/toutur/install.py
# remove hooks + skills from every harness (keeps your data)
$ python3 ~/toutur/install.py --uninstall

Questions

Does anything leave my machine?

No. Routing is local: stdlib Python plus, optionally, a local embedding model. The only network use is the install itself (cloning the repo) and the optional registry search behind route --source, which never runs on the hot path.

Which harnesses get a per-prompt hook?

Claude Code, Hermes, OpenCode, Antigravity and Cursor register native interceptors. Codex, Gemini CLI and OpenClaw get the skill + rulebook mandate (the agent runs the router itself). The coverage table on the overview page has the full matrix.

Will it slow my prompts down?

A warm route measures under 300 ms, inside every harness hook budget, with a 90-second cache for repeated prompts. If the router ever fails, every stage fails open — your message passes untouched.

What if a harness update breaks the wiring?

That's the self-heal: on every route Toutur verifies its mandate and interceptor, rewrites whatever an update undid, and logs the repair to ~/.tool-router/authority-heal.jsonl.
